# 示例笔记（examples）

本目录是一份**真实生成**的示例，用来展示「本地视频 → AI 富笔记」的产出效果。
直接用浏览器打开 `index.html` 即可查看——**不需要本地大模型、不需要联网**。

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 生成的富笔记：左侧视频位，右侧图文笔记（导读 / 目录 / 分节要点 / 考点 / 类比讲原理 / 代码说明+代码框 / 自测题） |
| `截图/` | 笔记内嵌的配图。**本示例中为自制知识要点卡片**（见下方「关于版权」） |
| `逐字稿.txt` | 音轨转写出的逐字稿，是工具产物之一。**本示例为作者自撰的演示稿**（见下方「关于版权」） |
| `assets/preview.png` | README 用的整页效果截图 |

> 注：示例中左侧视频源已改为一张首帧图（`poster`），因此脱离原视频也能正常打开、不会黑屏。
